## 🗺️ The Village Map

> *Every building here is something I've made. Step inside any of them.*

    <td width="50%" valign="top">
      <h3>🔭 The Watchtower</h3>
      <b><a href="https://github.com/Anushka-Verma-CODES/AboutDrone">Drone Trajectory Anomaly Detection</a></b> · <i>eyes on the sky</i>
      <br/><br/>
      Video in, suspicious flight paths out. <b>YOLO11</b> spots drones, ByteTrack follows them, a Kalman smoother cleans the path, and an anomaly ensemble (Isolation Forest, One-Class SVM, LSTM autoencoder) flags the odd ones, with a reason for each.

      <code>Python</code> <code>YOLO11</code> <code>PyTorch</code> <code>Streamlit</code>

      <br/><br/>
      A Java simulator of the <b>Raft consensus algorithm</b>, running a whole cluster on a virtual clock. Crash nodes, cut links, isolate the leader, then watch the cluster heal itself on a live JavaFX dashboard.
      <br/><br/>
      <code>Java</code> <code>JavaFX</code> <code>SQLite</code> <code>Distributed Systems</code>
